プライバシーポリシー

最終更新日: 2026年6月17日

「ChatTube」（以下、「当アプリ」といいます）は、ユーザーのプライバシーの保護に真摯に取り組んでいます。当アプリが収集・利用する情報について、以下の通りプライバシーポリシー（以下、「本ポリシー」といいます）を定めます。

1. 個人情報の収集と利用について

当アプリは、ログイン機能（YouTube/Twitch）を提供していますが、ログインに必要な認証情報（アクセストークンやCookie等）は、**すべてユーザー自身の端末内（セキュアなストレージ領域）でのみ暗号化して保存・管理**されます。

これらのログイン情報や、お気に入り登録されたチャンネルのURLなどの個人データが、当アプリの外部サーバーや第三者に送信されることは一切ありません。

2. 利用している外部サービスについて

当アプリでは、ライブ配信データの取得やチャットコメントの取得・投稿、および広告配信のために、以下の第三者が提供するサービスを利用しています。これらのサービスは、それぞれのポリシーに従って個人情報を収集・利用する場合があります。詳細は各サービスのプライバシーポリシーをご参照ください。

  • Google Play 開発者サービス / YouTube API Services
    当アプリは、YouTube Liveのチャット情報を取得・投稿するために YouTube API Services を使用しています。ユーザーは当アプリを利用することで、YouTubeの利用規約およびGoogleプライバシーポリシーに同意したものとみなされます。
    YouTube 利用規約 / Google プライバシーポリシー
  • Twitch API
    Twitchのチャット情報の取得・ログインコメント投稿のためにTwitch APIを使用しています。
    Twitch プライバシーポリシー
  • Google AdMob
    当アプリでは、一部画面にて広告を配信するためにGoogle AdMobを使用しています。AdMobはユーザーの関心に合わせた広告を表示するために、広告識別子（IDFA/AAID）等の匿名の情報を取得する場合があります。
    Google 広告ポリシーと規約

3. 情報のセキュリティについて

当アプリは、お気に入りURLやログインセッション情報などのデータをユーザーの端末内に保存するにあたり、Androidプラットフォームが提供するセキュリティ機能を最大限に活用し、外部からの不正アクセスや漏洩を防ぐように努めています。

4. プライバシーポリシーの変更について

当アプリは、法令の変更やアプリアップデートに伴い、本ポリシーを必要に応じて改定することがあります。改定されたポリシーは、当ページに掲載された時点より効力を生じるものとします。

5. 免責事項

当アプリの利用によって生じたトラブルや損失・損害等について、開発者は一切の責任を負いかねます。YouTubeやTwitchの仕様変更やAPIの停止等により、当アプリの一部または全部の機能が利用できなくなった場合も同様とします。

6. お問い合わせ

本ポリシーまたは当アプリの個人情報の取り扱いに関するご質問がございましたら、GitHubリポジトリのIssue、またはアプリストアに記載されているデベロッパーの連絡先までお問い合わせください。
